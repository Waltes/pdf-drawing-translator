# 1.1.12 —— 两组不同的引线说明被并成一句

1.1.11 交付后发现的一个排版缺陷，改动只有十几行，但印在图上会被客户读成
「红色部分包含边框和内撑」这种错误信息，所以单独发一版。

## 问题

无侧板分体托盘图纸第 1 页右侧，原文是**两组各自带引线**的说明：

- 上组（引线指红色底座）：`上面宽60mm，下面宽100mm，高度50mm` / `四角立柱下方底座红色部分`
- 中组（引线指蓝色边框）：`边框、内撑50*50*2.5mm` / `蓝色部分`

译文把两组合成了一条长串：

```
TOP WIDTH 60mm, BOTTOM WIDTH 100mm, HEIGHT 50mm.
BELOW THE FOUR CORNER POSTS FEET RED PART FRAME
AND INTERNAL BRACE 50×50×2.5mm BLUE PART
```

读下来就成了「红色部分包含边框和内撑」。位置没压线，两条引线也都在，但语义串了。

## 原因

段落合并的判据里有一条「间距 ≤ 2 倍字高」就算同一段。实测这一处的间距是
**27.0pt，1.78 倍字高**，没超过上限；真正让它连起来的其实是另一条判据——
**居中缩进**：中组首行左端比上一行缩进 24pt，但横向中心落在上一行范围内、
且更短，被判成「居中排的续行」。

而两组内部的行距是 1.0 / -0.2 / 0.4pt（框紧贴或交叠），和 27.0pt 差了一个量级。

## 改法

加一条**行距一致性**：同一段里折开的几行行距是均匀的，本行间距要和段内已有的
行距对得上，差超过 0.6 倍字高就断段。

用相对差而不是绝对阈值，是因为段内行距本身偏大的段落（行长、字大）不该受影响，
只有间距突然变化才说明换了一条信息。

改完这一处分成了两条：

```
TOP WIDTH 60mm, BOTTOM WIDTH 100mm, HEIGHT 50mm.
BELOW THE FOUR CORNER POSTS FEET RED PART          ← 指红色底座

FRAME AND INTERNAL BRACE 50×50×2.5mm BLUE PART     ← 指蓝色边框
```

## 回归

段落合并是公共逻辑，改动会影响所有走严格排版的图纸，所以逐份对比了合并后的
文字段数（段数变了就说明有段落被拆散或误并）：

| 图纸 | 改前段数 | 改后段数 | 越界 | 叠字 | 中文残留 |
|---|---|---|---|---|---|
| 托盘 11-10（5 页） | 46 | 46 | 0 | 0 | 0 |
| 托盘 11-12（5 页） | 50 | 50 | 0 | 0 | 0 |
| 黑色护栏（8 页） | 102 | 102 | 0 | 0 | 0 |
| 斜撑底座（3 页） | 68 | 68 | 0 | 0 | 0 |
| 新储物柜（2 页） | 20 | 20 | 0 | 0 | 0 |
| SledBox（1 页，英译中） | 53 | 53 | 0 | 0 | 0 |
| BR-01（7 页，英译中） | 254 | 253 | 0 | 2 | 0 |
| 无侧板分体托盘（4 页，本次新增） | 40 | 41 | 0 | 0 | 0 |

只有新图纸多了 1 段，正是这次要拆开的那一组；其余全部持平。BR-01 的 2 处叠字
与本次改动无关——用改动前的代码重跑，同样位置同样 2 处（英译中方向的长句
溢出，见「已知局限」）。BR-01 段数 254→253 是模型输出抖动，两次都能通读。

## 已知局限（不变）

- BR-01 第 3、6 页各有一处长句溢出，压到相邻标注上（英译中，源件是密集的
  3D 图 + 表格，框太窄）。
- 同页同类小标题字号不齐（挂在视图上方的那种，6.8~8.1pt）。
- 数量与尺寸混淆、模型自造长宽字母（`660l×70w×8mm`）等老问题未处理。
