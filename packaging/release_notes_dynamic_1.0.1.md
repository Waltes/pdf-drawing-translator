# PDF 翻译工具 DYNAMIC 定制版 1.0.1

## 这一版只改一件事：客户叫法只管标注，不管句子

1.0.0 里，只要原文出现「托盘」，译文里的 pallet 就换回 rack —— 不管这句话是
一个零件名还是一整段说明。客户提了：**这些词出现在整句或文章里，就不用遵守对译**。

现在按这个来：图上单独写着的部件标注、标题栏品名、视图名照客户的叫法写；
整句、成段说明按英文正常行文翻，不硬塞。

### 怎么区分

程序看三件事：

| 判据 | 结论 |
|---|---|
| 有谓语或连接词（采用、安装、焊接、固定、以免、防止……） | 算句子，不套客户叫法 |
| 拿掉客户词、数字、单位、符号后，剩的汉字超过 8 个 | 算句子，不套客户叫法 |
| 长度超过 30 字 | 算句子（多半是 OCR 把几行合成了一条） |
| 三条都不沾 | 算标注，按客户叫法写 |

**逗号不算句子的标志。** 图上 `托盘最下层，蓝色部分` 这种标注带逗号，
可它不是句子，那个位置就该写 rack。

第一版判据用的是「有逗号就算句子」，拿客户图纸一试就露馅了：图纸上的视图名
`临时护栏托盘俯视图` 被当成句子，客户要的叫法没进去。名词短语可以很长、
句子可以很短，字数分不开这两类，谓语能 —— 所以改成看有没有谓语。

### 实际效果（中→英）

| 原文 | 处理 | 结果 |
|---|---|---|
| 托盘 | 标注 | Pallet → **Rack** |
| 钢制护栏 | 标注 | Steel Guardrail → **Steel Barricade** |
| 临时护栏托盘俯视图 | 标注 | … Pallet Top View → **… Rack Top View** |
| 托盘最下层，蓝色部分 | 标注 | Bottom layer of the pallet → **…the rack** |
| 底层采用托盘堆叠，按颜色分区 | 句子 | Stacked on pallets, by colour zone **不动** |
| 底层采用托盘堆叠 | 句子 | Stacked on pallets **不动** |
| 托盘堆叠时应错位码放以免倾倒 | 句子 | Stack the pallets staggered… **不动** |

客户图纸实测（3.05 米护栏托盘示意图，5 页，中→英）：

- 标题 `临时护栏托盘俯视图` → **Barricade Rack**
- 正文 `托盘最下层，蓝色部分` → **Bottom layer of the rack, blue part**

### 提示词同步收口

给模型的交代也改了。1.0.0 的提示词写的是「译文里出现对应概念时必须照此写，
不许换同义词」，模型在整句里也会照做。现在写明：单独标注照写，整句按正常行文。

### 自检 57 → 58 项

新增「客户叫法只管标注不管整句」，两边都测：3 个整句不许改，3 个标注必须改。
只测「不许改」是不够的 —— 一个永远返回 False 的判断也能让那条通过，
等于功能关掉了还报通过。

## 通用版

这一版不跟。通用版按大众习惯走，不套特定领域的叫法；锁定词这套东西在通用版里
根本不加载（词表为空、提示词一字不加、自检两相关项都记「跳过」），
改与不改对它没有影响。
