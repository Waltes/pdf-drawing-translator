# PDF 翻译工具 DYNAMIC 定制版 1.1.0

## 一句话：从「重排版面」改成「原位替换」

1.0.x 的三个问题——字号乱、位置乱、符号错——不是三个 bug，是一个设计取向：
那套排版逻辑的目标是「让这一页排得好看」，代价是允许缩字号、挪位置、按内容
重心对齐。这条路线在通用场景下能救回本来会缩成一道灰线的标注，但客户要的
恰好相反：**图纸上每个位置都是他自己量过的，翻译工具没有权力重排**。

这一版按客户 2026-11-18 定的规则重做：

> 原文的位置，就是译文的位置，字号与原文保持一致。如果格式宽度不够，允许加长，
> 但不能超出图纸的格子。遇到超长会超出格子的，才允许换行显示。但要遵从翻译
> 目标语言的换行习惯，比如不能单词拆开。折行，必须翻译，不能保留原文。

## 六处改动

**一、字号锁死为原文墨迹高度**

原来是「在可读下限到原文大小之间二分，找能放下的最大字号」，所以同一行四条
文字可能写出四种大小（实测 19.38 / 15.67 / 13.62 / 13.82）。现在字号直接按
原文那一行字的实际墨迹高度反算，**不缩不放**。只有一种情况会缩：向右再也伸不
出去、折行也放不下——那时缩到能放下为止，绝不保留原文。

**二、位置锁死，只许向右延伸**

去掉四轮落点搜索（含上下挪一行、重心漂移）、类别统一字号、内容重心对齐。
左端锁在原文基线上，宽度不够就向右长，长到最近的障碍（竖线、相邻文字、图框）
为止。实测原来「表面处理：」左移了 82pt（29mm），现在左端偏差 1.3pt。

**三、被 OCR 切碎的一条，先拼回去再翻**

这是字号突然变小的真正原因，不是排版算的。实测「材料：外方管20*20*1.5mm，」
被切成两块，第一块只剩 42pt 宽，英文 MATERIAL: 要 48pt，放不下就一路缩到 9pt。

现在两道合并：
- **横向**：同一行上间距 ≤0.6 字高的碎块拼成一条。顺带解决了双冒号——
  OCR 把「数量：750片」切成「数量：」+「：750片」，两块各带一个冒号。
- **纵向**：同一段被按行切开的，拼成一段。判据是左端对齐或居中、下一行不含
  字段冒号、且不比上一行宽。右侧那个 90pt 宽的说明原来逐行排、缩到 5pt，
  合并后回到 10pt。

**四、大小写统一：全大写，单位小写**

中文源给不出大小写，原来的「看原文大写占比」在中文源上永远走 else 分支，
于是同一页里 MATERIAL 全大写、hot-dip galv. material 全小写。

现在按硬规则：**全部大写**，例外只有三类——SI 单位符号（mm、kg、m、Pa 永远
小写，MM 在国际单位制里是兆米）、已定型图纸缩写（QTY、THK、galv.）、
型号标准号（DN50、M8×30、ISO 2768）。

**五、标点与符号**

- 中文标点全部转英文，重复标点合并（`QTY::` → `QTY:`）
- 尺寸链里的星号换成乘号：`20*20*1.5mm` → `20×20×1.5mm`
- 逗号冒号后补空格，数字里的千分位和比例不动（`1,000`、`1:2` 保持原样）

**六、堵住误补直径符号 Ø**

`边框方管` 被判定成直径符号补进译文，成了 `Ø FRAME SQUARE`；`40×80×3m 方管`
成了 `40×80×3m ø sq.`。方管被标成圆管，比漏认一个符号严重。

两层闸门：插入位置只认 ASCII 数字和拉丁字母（原来用 `ch.isalpha()`，
Python 对汉字也返回 True）；插入点附近必须有数字（直径符号永远贴着数字写）。

## 客户对照表的两处增强

1. **术语保护**：翻译前把客户指定的叫法换成 `[[T0]]` 占位符，模型不参与命名。
   原来靠「勿用」列做黑名单，AI 每换一个词就得加一条——实测
   「临时护栏托盘俯视图」被译成 `TEMPORARY BARRICADE BRACKET`，bracket 不在
   禁用列表里，漏了。现在图上 `托盘` 一定是 RACK、`护栏` 一定是 BARRICADE。

2. **新增「指定写法」列**：想让某个词不按全大写、保持自己的写法时填在这里。
   - `pcs=PCS` 明确指定「pcs 写成 PCS」
   - `Rack` 只写形态时，rack 写成 Rack
   留空表示按默认规则（全大写 + 单位小写）。

## 仍然存在的限制（如实说明）

1. **窄框里的英文仍会变小**。中文「用于护栏与护栏连接」9 个字占 90pt，英文
   同等字号要 280pt。原位 + 不超框 + 字号不变，这三条在 90pt 的框里数学上
   不可能同时成立。现在的做法是折行优先、折不下才缩，并且缩到能放下为止。
2. **p5 一个标注都没识别出来**。那一页 OCR 没有返回任何结果，需要人工确认是
   空页还是识别失败。
3. **AI 偶尔漏词**。p2 源「在25×1.5mm方管上钻10mm通孔」译成
   `IN THE 25 SQUARE TUBE`，`×1.5mm` 丢了。复核会把它挑出来重译，这一处
   重译后仍未解决。
4. **`AØ20` 少一个空格**。p2 的 `A Ø20 mm` 被写成 `AØ20 mm`，不影响识读，
   但排印上是瑕疵。
