# DYNAMIC 定制版 1.1.8

2026-11-19

## 这一版解决什么

无侧板分体托盘图纸第 1 页右侧，原文是**两组各自带引线**的说明：

- 上组（引线指红色底座）：`上面宽60mm，下面宽100mm，高度50mm` / `四角立柱下方底座红色部分`
- 中组（引线指蓝色边框）：`边框、内撑50*50*2.5mm` / `蓝色部分`

1.1.7 把两组并成了一条：

```
TOP WIDTH 60mm, BOTTOM WIDTH 100mm, HEIGHT 50mm.
BELOW THE FOUR CORNER POSTS FEET RED PART FRAME
AND INTERNAL BRACE 50×50×2.5mm BLUE PART
```

读下来成了「红色部分包含边框和内撑」。字没压线，引线也都在，但意思错了。

## 为什么会并

段落合并用「间距 ≤ 2 倍字高」判同一段。这一处间距 27.0pt（1.78 倍字高），
刚好没超过上限。让它连起来的其实是另一条判据——**居中缩进**：中组首行左端
缩进 24pt，但横向中心落在上一行范围内、且更短，被判成「居中排的续行」。

而两组内部的行距只有 1.0 / -0.2 / 0.4pt（框紧贴或交叠），和 27.0pt 差了一个量级。

## 改法

加一条**行距一致性**：同一段里折开的行，行距是均匀的；本行间距和段内已有行距
差超过 0.6 倍字高，就判为换了一条信息，断段。

用相对差而不是绝对阈值，段内行距本身偏大的段落不受影响。

改完图上分成两条，各自贴着自己的引线：

```
TOP WIDTH 60mm, BOTTOM WIDTH 100mm, HEIGHT 50mm.
BELOW THE FOUR CORNER POSTS FEET RED PART

FRAME AND INTERNAL BRACE 50×50×2.5mm BLUE PART
```

## 仍然没解决的

1. **BR-01 英译中方向两处长句溢出**（第 3、6 页），压到相邻标注上。源件是密集的
   3D 图与表格，框太窄，中文比英文长，塞不进原位。
2. **同页同类小标题字号不齐**，挂在视图上方的那种（6.8~8.1pt）仍按各自源字高反算。
3. **数量与尺寸混淆**：`12mm黑色模板*4片` 会译成 `4×12mm BLACK TEMPLATE`。
4. **模型自造长宽字母**：`660l×70w×8mm` 这类写法未处理，只出现过一次。
5. **`Omm` 假未译**：OCR 把某处尺寸的 0 认成字母 O，这条不需要翻译、原样保留，
   图上无异常，属 OCR 噪声。
